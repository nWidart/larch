```php
arch('billing uses only shared, and the public API of catalog')
    ->expect(module('Billing'))
    ->toOnlyDependOn(module('Shared'), module('Catalog')->publicApi())
    ->via(Edge::all());
```

```
Module Billing may only depend on Shared, Catalog (public API). 1 link breaks it:

  Modules/Billing/app/Actions/ChargeOrder.php:18
    Modules\Billing\Actions\ChargeOrder uses Modules\Inventory\Internal\StockLedger
    through the facade Modules\Shared\Facades\Stock, bound in Modules/Inventory/app/Providers/InventoryServiceProvider.php:13
    Billing may not depend on Inventory.
```

	<Card title="Sees what imports hide" icon="magnifier">
		Facades, container keys, event listeners and dispatched jobs link modules without an import.
		Larch reads them from the booted app.
	</Card>
	<Card title="Rules on the app, too" icon="approve-check">
		Routes need their middleware, models need a policy, queued jobs set retry limits.

	<Card title="Adopt it today" icon="rocket">
		A baseline accepts the violations an app already has, so CI fails only on new ones.
	</Card>
	<Card title="A map of your modules" icon="puzzle">
		`php artisan larch:graph` exports every link between modules, as JSON or as an HTML report.
